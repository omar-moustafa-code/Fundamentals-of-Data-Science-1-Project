# Fundamentals of Data Science 1 Project

## Overview
This project applies data science techniques to analyze health-related data, with a focus on building predictive models and extracting meaningful insights. The analysis utilizes logistic regression for classification, `ggplot2` for advanced data visualization, and a thorough examination of relationships within the dataset. This was completed as the term project for a fundamentals of data science course.

## Repository Contents
*   **`Omar's_Heart_Notebook - Project.ipynb`**: The Jupyter Notebook containing the primary analysis, model building, and visualizations. (Note: The notebook's extension suggests it may have been used with R or Python, but the project heavily features R-based tools).
*   **`Omar's Project R.pdf`**: The compiled PDF report detailing the methodology, results, and conclusions.

## Key Methods and Techniques
*   **Logistic Regression**: Implemented to predict binary outcomes (e.g., presence or absence of a condition) based on key predictor variables.
*   **Data Visualization with `ggplot2`**: Used to create compelling and informative graphics that illustrate relationships and patterns in the data.
*   **Relationship Analysis**: Conducted a thorough analysis of existing relationships between variables to uncover significant correlations and drivers.
*   **Insight Extraction**: Focused on translating analytical findings into clear, actionable conclusions.

## How to Reproduce This Work
1.  Clone this repository to your local machine.
2.  Ensure you have the necessary environment set up. The analysis uses a combination of tools. Check the notebook for specific package requirements (e.g., R libraries like `ggplot2` if the notebook uses an R kernel, or Python libraries like `pandas` and `scikit-learn` if it uses a Python kernel).
3.  Open the `Omar's_Heart_Notebook - Project.ipynb` file in Jupyter Notebook.
4.  Run the code cells sequentially to reproduce the analysis and visualizations.
